# kotlin_lab6_dilnura — Laboratory 6: Special Classes

Kotlin/JVM project with runnable solutions for all 15 tasks from the supplied laboratory document.

## Run in IntelliJ IDEA
1. Open this folder as a Gradle project.
2. Wait for Gradle sync to finish.
3. To run all tasks from the menu, run `src/main/kotlin/lab6/Main.kt`. To run one task separately, open `src/main/kotlin/task01/Main.kt` (or task02 ... task15) and click the green triangle beside `fun main()`. You can also use the Gradle `run` task to launch the menu.

## Run from terminal
Requires JDK 19+ and Gradle (or use the Gradle wrapper generated by IntelliJ):
```bash
gradle run
```

The launcher shows a menu. Enter a task number from 1 to 15. Each task reads its own console input.
Kotlin 2.2.20 is configured because Task 13 uses `when` guard conditions.
